# BidaiaNomad · Inicio

Página del enlace de la bio de Instagram: imita la pantalla de inicio de un móvil con accesos a la web,
la asesoría, el contacto, la app de clientes, WhatsApp, Instagram, TikTok y la newsletter.

- **Hecha con**: React + Vite + Tailwind. Se publica sola en Vercel al subir cambios a `main`.
- **Textos y enlaces**: todos en `src/config/siteConfig.ts`.
- **Iconos y foto**: `public/app-icons/` y `public/daniel.png`.

```bash
npm install
npm run dev     # verla en local
npm run build   # comprobar que compila
```
